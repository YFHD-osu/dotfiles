# 整體要求
生成一份實驗報告，其格式必須嚴格遵守實驗報告範例，不可以擅自修改新增、刪除區段。
報告內容部分用字必須遵守講義或實驗報告的用詞，即使不準確也盡量用課程中的文字來論述，不要找外部的專有名詞替代。
圖片生成部分請使用 word 內部的圖形工具繪製，如果無法操作或可能導致排版錯亂，也請用 mermaid 等工具寫好程式後進行輸出，不要直接生成圖片。
專業術語不是本次實驗所強調的就不要打說明，如果要說明專業術語不要在後面打括號。
舉例不要使用 <名詞>(<說明>)，直接說"例如：<說明>"
圖片必須使用"圖{阿拉伯數字} {說明}" 的格式標示，不要使用國字，不要加入頓號，每張圖片必須要在文中被引用。
程式碼部分使用寬度為 6.69"，並且套用 Code spinnet 語法標示 ，每段被放上來的程式皆需要有說明，盡量將所有程式碼都放上並給予解釋，如果實在太長在擇重要的放上

## 二、頁面設定

1. 紙張大小：**A4**（頁寬 11906 twips × 頁高 16838 twips）。
2. 版面邊界：**上、下、左、右各 2 cm**（1134 twips）。
3. 頁首距離 1.5 cm、頁尾距離 1.75 cm。
4. 頁碼：
   - 位置：**頁尾置中**（水平置中）。
   - 字型：Times New Roman、**10 pt**。
   - 格式：阿拉伯數字，以 `PAGE` 欄位自動編號，自封面起連續編號。
   - **首頁（封面）不顯示頁碼**：勾選「首頁不同」。
5. 封面單獨一頁，正文自新頁開始（範本在第一章標題前插入分頁符號）。
6. 文件格線：每頁 18 pt（僅影響空白行的行高，不影響固定行高段落）。

## 四、正文

### 4.1 文字格式

| 屬性 | 設定 |
|---|---|
| 中文字型 | 標楷體 |
| 西文字型 | Times New Roman（英文、數字、半形符號） |
| 字級 | 14 pt |
| 行距 | **固定行高 20 pt**（line = 400, lineRule = exact） |
| 對齊 | **左右對齊** |
| 段前／段後 | 0 pt |
| 縮排 | 左縮排 **0.85 cm（約 2 字元）**，首行不另縮排 |

- 全形標點（，。、：；）使用標楷體；半形符號與數字使用 Times New Roman。
- 特殊符號（°、±、μ、Ω…）請以「插入符號」方式輸入，不要用注音或拼字湊出。
- 範本中以**紅色粗體**標示的文字為填寫說明，正式繳交前請全部刪除並替換為自己的內容。

### 4.2 章節標題

- 編號格式：**一、二、三、四、五、**（中文數字，自動編號）。
- 字級 14 pt、**粗體**、左右對齊（實務上靠左）。
- 行距同正文：固定 20 pt。
- 標題與前一段之間**空一行**（20 pt）。
- 標題文字前不額外空格；編號由 Word 清單自動產生。
- 五個固定章節依序為：
  1. 一、實習目的
  2. 二、實習設備及使用零件
  3. 三、工作原理及預期結果
  4. 四、實習結果與討論
  5. 五、小組分工

### 4.3 條列清單（設備與零件）

- 使用阿拉伯數字編號：`1.`、`2.`、`3.`…
- 字級 14 pt、行距固定 20 pt。
- 編號靠左邊界，文字起始位置約 1.7 cm（懸掛縮排 0.85 cm）。
- 每項列出一個設備或零件，例如：
  1. NVIDIA Jetson TX2
  2. NVIDIA Jetson Xavier NX
  3. PC, OS

## 五、圖的格式

1. 圖片**置中**排列，寬度依內容調整且不得超出 17 cm 版心；範例尺寸為 6.03 × 4.01 cm。
2. 圖說置於**圖的下方**、**置中**、**11 pt**。
3. 圖說格式：`圖N 說明文字`（N 為阿拉伯數字，N 與說明之間空一個半形空格）。
4. **圖與圖說之間不空行**。
5. 圖組與上下文字敘述之間**各空一行**（20 pt）。
6. 圖號依出現順序遞增：圖1、圖2、圖3…
7. 正文需先以文字敘述引用圖（例如「如圖1所示」），再放置圖片。

```
（空一行）
　　　　　　［圖片］
圖1 圖片說明置中放於圖下
（空一行）
```

## 六、表的格式

1. 表說置於**表的上方**、**置中**、**11 pt**。
2. 表說格式：`表N 說明文字`（N 為阿拉伯數字）。
3. 單位的標示（如「單位：°C」）放在表說與表格之間，**靠右對齊**、**8 pt**。
4. 表格與上下文字敘述之間**各空一行**（20 pt）。
5. 表格框線：**單線 0.5 pt**，外框與內部框線皆同。
6. 表頭文字：**10.5 pt、置中**；表格內容：**11 pt、置中**。
7. 儲存格內容**垂直置中**，行距固定 20 pt。
8. 表格整體對齊頁面中央（範本以左縮排 3.37 cm 呈現，視覺上略偏左；建議直接設定表格置中）。
9. 表號依出現順序遞增：表1、表2、表3…
10. 正文需先引用表（例如「如表1所示」），再放置表格。

範例（表1：阿里山與日月潭溫度）

|  | 阿里山溫度 | 日月潭溫度 |
|---|---|---|
| 一月 | 15 | 14 |
| 三月 | 20 | 21 |
| 五月 | 22 | 23 |

## 附錄 B、模板已知問題（沿用時請修正）

1. **封面多出一頁空白頁**：範本第 2 頁為空白，導致正文第一頁頁碼為 3。原因是封面空白行過多，加上章節前的分頁符號。請刪減封面空白行，讓正文自第 2 頁開始。
2. **封面日期缺字**：`中華民國115年月日` 的年、月、日數字為空，轉 PDF 後顯示為方框。請填入實際日期。
3. **圖說段落帶有首行縮排 480 twips**：會使圖片與圖說略微偏右。建議將該段落縮排歸零後再置中。
4. **表1 未真正置中**：以左縮排 1908 twips 擺放，左右留白不對稱。建議改用「表格置中」。
5. **內文左縮排而非首行縮排**：範本每一行都縮排 0.85 cm。若要與範本完全一致請照設；若要求標準中文排版，可改為「首行縮排 2 字元」。
6. **表說行距不一致**：表說為固定 20 pt，圖說為單行間距；建議統一為單行間距或固定 20 pt。
7. 「以藍色筆登記」為舊版手寫報告用語，電子報告可忽略。
